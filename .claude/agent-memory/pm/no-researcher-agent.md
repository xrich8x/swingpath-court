**There is no `researcher` teammate. The founder removed the role on 2026-09-18** (commit c1c9d89,
"Remove the researcher role: agent, journal, memory and every live reference").

**Why:** the founder's call. Earlier docs — including rows in `docs/STATE.md` and my own older memories —
still speak of "the research note" or "research owns §4.1". Those are historical attributions, not live
routing.

**How to apply:**
- Never write "commission this from researcher" in a brief, a handoff or a DECISIONS_PENDING entry. The
  investigation goes to the lead, or to `backend-dev` as a pre-registered experiment.
- The live team is **pm, backend-dev, frontend-dev, qa** (plus the lead). Three live agents project-wide.
- When an older doc cites a researcher finding, quote the finding and its evidence file; do not imply the
  role still exists.
